Kobayashi Bot v2.0.3 — Dragon RPG Reset System

/zerarrpg
- Somente o dono principal.
- Deve ser usado dentro de um grupo.
- Apaga os personagens RPG pertencentes aos membros atuais daquele grupo.
- Confirmação: /zerarrpg confirmar

/zerarrpgg
- Somente o dono principal.
- Apaga TODOS os personagens do banco Dragon RPG em todos os grupos.
- Inclui o personagem do próprio dono do bot.
- Confirmação: /zerarrpgg confirmar

SEGURANÇA
- Antes de apagar personagens, o bot cria automaticamente um backup em:
  files/database/backups/dragon-rpg/
- O Level social normal da Kobayashi não é afetado.
- Após o reset, o jogador usa /rpgcriar para começar novamente.
