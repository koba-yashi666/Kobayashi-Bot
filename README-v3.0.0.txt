KOBAYASHI BOT v3.0.0 — MEGA INTEGRAÇÃO

Objetivo:
Unificar a Kobayashi com ideias/sistemas locais das bases Nazuna e Hutao,
mantendo a identidade, permissões, menus e arquitetura da Kobayashi.

Principais pontos:
- Compatibilidade de aliases de administração, grupos, stickers, aluguel, RPG e diversão.
- Nova Central /menuv3.
- Ferramentas locais sem API.
- AntiPalavra por grupo.
- Auto respostas por grupo.
- Preservação integral dos sistemas Kobayashi v2.x.
- APIs externas/downloads ficaram intencionalmente para uma etapa separada.

Arquivos de banco em files/database não são sobrescritos pelo ZIP.
