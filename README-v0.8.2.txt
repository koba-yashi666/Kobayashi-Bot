Kobayashi Bot v0.8.2 — Configuração por grupo

Novidades:
- /configgp mantém o painel geral do grupo.
- /configgp exportar gera um código KCFG1 com as configurações salvas do grupo.
- /configgp restaurar <código> restaura o backup no grupo em que o comando foi usado.
- O backup ignora bancos claramente relacionados a logs, mensagens, níveis, XP, coins, inventário, advertências e aluguel.
- A restauração altera somente a chave do grupo atual e preserva os dados dos outros grupos.

Observação:
Este é um pacote incremental. Extraia por cima da instalação atual do Kobayashi Bot.
