Kobayashi Bot v2.0.23 — Pacotes + Novidades + Menus

PACOTES
/pacote fig on
- inicia captura no chat atual;
- todas as figurinhas recebidas enquanto estiver ativo são armazenadas temporariamente.

/pacote fig off
- encerra a captura sem apagar o que já foi coletado.

/pacote add Nome do pacote
- registra todo o conteúdo capturado;
- se já existir um pacote com o mesmo nome, ele é substituído.

/pacote Nome do pacote
- envia todas as figurinhas registradas no pacote.

/figurinha Nome do pacote
- envia uma figurinha por uso;
- avança automaticamente e volta à primeira ao chegar ao fim.

/pacote lista
- mostra os pacotes registrados.

NOVIDADES
- /novidades agora detecta a maior versão semanticamente.
- versões antigas no topo do JSON não prendem mais o comando.
- novos comandos aparecem em uma seção própria.

MENUS
- /pacote, /figurinha e /rgfigu no menu de figurinhas.
- /rankadm, /resetrankadm e /listanegra no menu ADM.
- daqui em diante, comando novo deve entrar no menu correspondente e no /novidades.
