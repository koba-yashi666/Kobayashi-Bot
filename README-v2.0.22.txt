Kobayashi Bot v2.0.22 — Anti-PV 3 Modos

/antipv aviso
- avisa a pessoa que o PV do bot é protegido;
- notifica o dono com número, ID, tipo e conteúdo;
- não bloqueia o contato no WhatsApp.

/antipv bloquear
- avisa a pessoa;
- tenta bloquear o contato via Baileys updateBlockStatus;
- notifica o dono;
- não processa comandos/mensagens desse contato.

/antipv aluguel
- redireciona o contato para o aluguel da Kobayashi;
- usa o link:
  https://wa.me/5515997075304?text=Quero%20alugar%20o%20bot%2C%20como%20fa%C3%A7o%3F
- notifica o dono;
- não processa comandos/mensagens do contato.

/antipv off
- desativa a proteção.

Compatibilidade:
- configurações antigas com antiPv=true passam a ser tratadas como modo aviso.
