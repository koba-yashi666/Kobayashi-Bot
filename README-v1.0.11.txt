KOBAYASHI BOT v1.0.11 — MODORPG AUTOMÁTICO

O comando /modorpg agora alterna o estado do RPG sem precisar escrever on ou off.

- Se o RPG estiver ativo, /modorpg desativa.
- Se o RPG estiver desativado, /modorpg ativa.
- Funciona apenas em grupos.
- Apenas administradores podem alterar o estado.
- /rpg continua abrindo o menu do Dragon RPG.

Esta atualização é cumulativa e também preserva a integração do Sentinel WA da v1.0.10.
Nenhum arquivo de sessão ou banco de dados está incluído no ZIP.
